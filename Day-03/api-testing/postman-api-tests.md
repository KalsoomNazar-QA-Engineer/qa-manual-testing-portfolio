# Postman API Testing Practice

## Objective

I practiced sending API requests using Postman and verifying the responses.

## HTTP Methods Tested

| Method | Purpose              |
| ------ | -------------------- |
| GET    | Retrieve data        |
| POST   | Create new data      |
| PUT    | Update existing data |
| DELETE | Delete data          |

## Test 1 — GET Request

**Method:** GET
**Purpose:** Retrieve data

**Expected Result:**
The API should return the requested data with a successful status code.

**Status Code:** 200 OK

## Test 2 — POST Request

**Method:** POST
**Purpose:** Create new data

**Expected Result:**
The API should create the requested resource and return a successful response.

**Status Code:** 201 Created

## Test 3 — PUT Request

**Method:** PUT
**Purpose:** Update existing data

**Expected Result:**
The API should update the requested resource successfully.

## Test 4 — DELETE Request

**Method:** DELETE
**Purpose:** Delete existing data

**Expected Result:**
The API should delete the requested resource successfully.

## Response Validation

During API testing, I checked:

* HTTP status code
* Response body
* Response data
* Error messages
* Actual result vs expected result

## Key Learning

I learned how to send different types of API requests in Postman and validate the returned response.
