# API Response Validation

## Objective

I practiced validating API responses in Postman.

## Validation Checks

* HTTP status code
* Response body
* Response data
* Response format
* Error messages
* Response time

## Example

**Request:** GET

**Expected Status Code:** `200 OK`

**Actual Status Code:** `200 OK`

**Result:** Pass

The response was checked to verify that the returned data matched the expected result.

## Key Learning

I learned that API testing is not only about checking the status code. The response body, data, format, error handling, and response time should also be validated.
