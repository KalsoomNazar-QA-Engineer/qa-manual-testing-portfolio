# Day 03 — API Testing & Postman

## Objective

Today I practiced the basics of API testing using Postman.

## Topics Covered

* API Testing
* HTTP Methods
* HTTP Status Codes
* GET, POST, PUT & DELETE
* Request & Response
* Postman

## Practical Work

* Sent API requests using Postman
* Tested GET, POST, PUT and DELETE methods
* Verified HTTP status codes
* Checked response data
* Compared the actual response with the expected result

## Key Learning

I learned how APIs communicate through requests and responses and how Postman can be used to test API functionality.
