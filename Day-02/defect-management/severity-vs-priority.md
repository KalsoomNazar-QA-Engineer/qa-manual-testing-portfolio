# Severity vs Priority

## Severity

Severity defines **how much a defect impacts the system or functionality**.

## Priority

Priority defines **how urgently a defect should be fixed**.

## Practical Examples

| Bug                                             | Severity | Priority |
| ----------------------------------------------- | -------- | -------- |
| Application crashes when user logs in           | High     | High     |
| Login button text is misspelled                 | Low      | Low      |
| Important feature is not working before release | High     | High     |
| Minor UI alignment issue                        | Low      | Medium   |

## Key Learning

Severity focuses on the **impact of the defect**, while priority focuses on the **urgency of fixing it**. Both can be different depending on the situation.
