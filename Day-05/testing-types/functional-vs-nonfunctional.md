# Functional vs Non-Functional Testing

## Example: Login Functionality

### Functional Testing

Functional Testing verifies whether the system performs its required functions correctly.

| Test Scenario                | Expected Result                   |
| ---------------------------- | --------------------------------- |
| Login with valid credentials | User should log in successfully   |
| Login with invalid password  | Error message should be displayed |
| Submit empty login fields    | Validation messages should appear |
| Logout from the application  | User should be logged out         |

### Non-Functional Testing

Non-Functional Testing verifies how well the system performs.

| Testing Area  | Example                                          |
| ------------- | ------------------------------------------------ |
| Performance   | Login page should load within an acceptable time |
| Security      | Password should be masked and protected          |
| Usability     | Login interface should be easy to understand     |
| Compatibility | Login should work across supported browsers      |

## Key Learning

Functional Testing focuses on **what the system does**, while Non-Functional Testing focuses on **how well the system performs**.
