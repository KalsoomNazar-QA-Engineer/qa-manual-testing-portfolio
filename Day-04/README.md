# Day 04 — Smoke, Sanity & Regression Testing

## Objective

Today I practiced understanding and differentiating Smoke, Sanity, and Regression Testing.

## Topics Covered

* Smoke Testing
* Sanity Testing
* Regression Testing
* Retesting

## Practical Work

* Identified core functionality for Smoke Testing
* Identified changed functionality for Sanity Testing
* Identified existing functionality for Regression Testing
* Practiced the difference between Retesting and Regression Testing

## Key Learning

Smoke Testing checks whether a build is stable enough for further testing.

Sanity Testing focuses on a specific changed or fixed area.

Regression Testing verifies that existing functionality has not been affected by new changes.

Retesting verifies whether a specific defect has been fixed successfully.
