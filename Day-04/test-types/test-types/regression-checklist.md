# Regression Test Checklist

## Objective

To create a checklist for verifying that existing login functionality still works after a change.

## Module

Login

## Regression Test Checklist

| Test Case ID | Test Scenario                       | Expected Result                                   |
| ------------ | ----------------------------------- | ------------------------------------------------- |
| REG-01       | Login with valid credentials        | User should log in successfully                   |
| REG-02       | Login with invalid password         | Error message should be displayed                 |
| REG-03       | Submit login form with empty fields | Appropriate validation should appear              |
| REG-04       | Verify password masking             | Password should be displayed as masked characters |
| REG-05       | Verify logout functionality         | User should be logged out successfully            |

## Execution Status

Not Executed — Checklist prepared for practice.

## Key Learning

Regression testing helps verify that existing functionality continues to work after software changes.
