# Day 01 — Manual Testing Fundamentals

## Topics Covered

### 1. QA vs QC

* **QA (Quality Assurance):** Focuses on improving processes to prevent defects.
* **QC (Quality Control):** Focuses on identifying defects in the product.

### 2. Verification vs Validation

* **Verification:** Are we building the product correctly?
* **Validation:** Are we building the right product?

### 3. SDLC & STLC

* **SDLC:** Software Development Life Cycle
* **STLC:** Software Testing Life Cycle

### 4. Functional vs Non-Functional Testing

* **Functional Testing:** Verifies what the system does according to requirements.
* **Non-Functional Testing:** Verifies how well the system performs, such as performance, security, usability, and reliability.

### 5. Positive & Negative Testing

* **Positive Testing:** Testing with valid inputs to verify expected behavior.
* **Negative Testing:** Testing with invalid or unexpected inputs to verify proper error handling.

### 6. Test Scenario vs Test Case

* **Test Scenario:** High-level description of what needs to be tested.
* **Test Case:** Detailed steps, test data, and expected results used to verify a scenario.

### 7. Test Data

Test data is the input used during test execution, such as usernames, passwords, numbers, or other required values.

### 8. Expected Result vs Actual Result

* **Expected Result:** What should happen according to the requirement.
* **Actual Result:** What actually happens when the test is executed.

## Practical Understanding

I practiced applying these concepts to common application features, including login functionality, by identifying scenarios, test cases, valid/invalid inputs, and expected results.
